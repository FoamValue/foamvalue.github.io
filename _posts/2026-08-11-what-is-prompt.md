## 一句话说清楚

**Prompt（提示词）** 就是你输入给 AI 的那段话——你问的问题、下的指令、给的背景信息，统统都叫 Prompt。

它是你和 AI 之间的"翻译官"：你说的话好不好，AI 能听懂多少，90% 取决于 Prompt 写得好不好。

> 这不是什么高深的技术概念。你每一次跟 ChatGPT 说"帮我写个文案"，都是在写 Prompt。

## 一个比喻帮你理解：AI = 超级实习生

把 AI 想象成一个知识渊博、但完全不会主动思考的实习生。

![AI 类比超级实习生](/assets/images/prompt-analogy.svg)

看出区别了吗？**问题不在实习生（AI）的能力，而在你给的指令（Prompt）够不够清晰。**

## 新手最常见的三个误区

### 误区一：把 AI 当搜索引擎

```
❌ "量子计算是什么？"
✅ "用初中生能听懂的话，解释量子计算是什么，举一个生活例子"
```

搜索引擎给你链接，而 AI 给你答案。所以你需要告诉它"答案长什么样"。

### 误区二：一次只问一句话

很多人跟 AI 聊天，每次只说一句话，AI 回答完就换一个话题。这就像你让一个厨师做菜，每次只说"切菜"，不说"做什么菜、什么口味、几个人吃"。

**一次性把背景信息给足，AI 才能给出好答案。**

### 误区三：AI 答得不好就放弃

AI 第一次回答不满意，很正常。调整一下 Prompt 再问一次，效果可能完全不同。

> 你会发现：**90% 的情况不是 AI 太笨，而是你的 Prompt 不够精确。**

## 写好 Prompt 的四大要素

一个高质量的 Prompt 其实就四个部分，记住这个框架，你的 Prompt 水平立刻超过 80% 的人：

![Prompt 四大要素](/assets/images/prompt-elements.svg)

### 1. 角色（Role）—— 让 AI 带入身份

告诉 AI "你是谁"，它就会用这个身份的语言风格和知识背景来回答。

```
你是一位资深心理咨询师 → 回答会温暖、专业、有共情
你是一位毒舌影评人 → 回答会犀利、幽默、一针见血
```

### 2. 任务（Task）—— 明确告诉 AI 做什么

任务要具体、可衡量。不要只说"分析一下"，要说"分析以下几点，每点不超过 50 字"。

### 3. 上下文（Context）—— 给足背景信息

AI 不"认识"你，它不知道你的项目背景、用户群体、过往讨论过什么。**你需要把这些信息喂给它。**

```
❌ "帮我写个活动方案"
✅ "我们公司是做少儿编程的，下个月要办一场线上编程比赛，
    参赛者是 8-12 岁的小朋友，帮我写一个活动执行方案"
```

### 4. 格式（Format）—— 规定输出样式

不说格式，AI 会按它自己的习惯输出。你可以指定：

- 用表格还是列表
- 写多少字
- 语气正式还是轻松
- 分几个部分

### 拼在一起看效果

```
❌ 模糊版："写一篇关于环保的文章"

✅ 精准版：
"作为一名高中地理老师（角色），
请写一篇 800 字的科普短文（任务），
面向高一学生解释'碳达峰'和'碳中和'的区别（上下文），
多用生活化比喻，少用专业术语，用三个小标题分段（格式）。"
```

## 三个进阶技巧，从入门到熟练

### 技巧一：零样本提示

直接问，不给例子。适合简单问题：

```
"翻译'你好'为英文。"
```

### 技巧二：少样本提示

给 1-3 个例子让 AI 模仿，适合需要特定格式的输出：

```
请按这个格式回答问题：
问：快乐的反义词是什么？
答：快乐的反义词是悲伤。

问：炎热的反义词是什么？
答：炎热的反义词是寒冷。

问：成功的反义词是什么？
答：
```

### 技巧三：思维链（Chain of Thought）

让 AI 把推理过程一步步写出来，适合复杂问题：

```
"请一步步推理：小明有 5 个苹果，小红比小明多 2 个，
他们一共有多少个苹果？"
```

AI 会这样回答：
```
1. 小明有 5 个苹果
2. 小红有 5 + 2 = 7 个苹果
3. 一共：5 + 7 = 12 个苹果
```

## 实战中常见的坑

| 场景 | 踩坑写法 | 优化写法 |
|------|---------|---------|
| 写文案 | "帮我写个广告" | "帮我写一个针对 25-35 岁职场妈妈的护肤品广告，突出'安全温和'，150 字以内" |
| 改代码 | "这段代码有 Bug" | "这段 JavaScript 代码在 Chrome 上运行报错，错误信息是 xxx，帮我排查原因" |
| 学知识 | "解释一下机器学习" | "我是一个零编程基础的产品经理，用 3 个生活例子解释机器学习的三种主要方式" |

## 总结

| 要点 | 一句话 |
|------|--------|
| Prompt 是什么 | 你跟 AI 说的话，就是 Prompt |
| 最核心的比喻 | AI 像超级实习生，指令越清晰，输出越好 |
| 写好 Prompt 的四要素 | 角色 + 任务 + 上下文 + 格式 |
| 新手最大误区 | 把 AI 当搜索引擎，一次只问一句话 |
| 进阶技巧 | 给例子、让 AI 分步推理 |

**最后送你一句话：** 跟 AI 沟通就像跟人沟通——你把话说清楚，对方才能把事情做明白。你的 Prompt 写得越好，AI 就越懂你。
